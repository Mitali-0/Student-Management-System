# Student Management System in C

A menu-driven console application developed using C to manage student records.

## Features
- Add student records
- Display student details
- Search for a student
- Update student records
- Delete student records

## Concepts Used
- Structures (`struct`)
- Arrays
- Functions
- Loops and conditional statements
- String handling

## Purpose
Created as a beginner project to practice C programming fundamentals and understand how student records can be managed through a simple application.

## Language
C
